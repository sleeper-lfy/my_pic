# 先建立公开人体参照，再实现角色动画

上一轮人形已被用户否决。新的起点是官方公开人体网格、真实父子骨架、官方蒙皮权重及原生动作数据。暂不重做AI原画，也不把失败的2D拆件继续加宽拉长。原目标的3.5头身仅在基础解剖确认后进行整体造型设计。

## 没有采用的候选

Quaternius公开pack页面仍出现CC0文字，但可读取的官方站点源码中，更新后的许可页出现QAL及资产单独再分发限制；来源之间存在冲突，不能把“网上免费”当作可直接收进公开仓库。本轮不下载或再分发其资产。CMU和Blender Studio页面在当前网络下部分访问被403拒绝，未将未核实文件当作已获资源。

具体网络观察及许可依据见 `public-reference-motion-research.md`。没有使用未知镜像绕开来源限制，也没有从社区混入许可不明的人物或攻击动作。

## 实现改动

1. 从官方OBJ建立连续body表面，保留原顶点映射，排除helper/joint等辅助几何。以163骨的原生joint顶点定位建立真实父子层级，而非独立线段。
2. 应用官方139组权重；可见顶点的权重按比例归一化，不用自动重绑偷偷替换原权重。Armature modifier直接驱动人体表面。
3. 先保留自然身材和全身完整轮廓，输出正/背/侧/左右45°及手部近景。骨架叠加图来自实际骨骼投影。
4. 通过骨旋转做局部蒙皮压力检查，检查连续采样中的3D骨长与实际表面变形；这是明确标记的本地测试动作，不能称为下载的持锤动画。
5. 独立播放MakeHuman行走BVH本身的骨架；另对RiggedFigure原生skin+clip逐时刻求值验证。二者都不借用二维关节点插值，也不假称已完成跨骨架重定向。
6. 旧入口默认关闭，必须显式`--legacy-diagnostic`才能重现失败。历史图片保留，但人工状态已更新为rejected。

## 复跑

在 `ai-game-art-factory` 目录，已有Blender须位于PATH：

```sh
python scripts/factory.py reference-baseline --kind anatomy
python scripts/factory.py reference-baseline --kind motion
python scripts/factory.py test
```

第一条运行 `workflows/blender/public_human_baseline.py`，再由 `public_human_review.py`整理审查图。第二条调用 `public_motion_probe.py`及其review脚本。源文件在仓库内，复跑不需要访问下载站或AI服务。图像和机器可读结果分别在 `previews/public_human/`、`previews/public_motion/`、`reports/public_human/`、`reports/public_motion/`。

## 接下来的验收顺序

先看素体有没有完整、自然可辨的头颈、肩带、胸廓、骨盆、双手双腿；再看原生骨架层级和连续变形。基础通过后，才进行行走重定向、角色整体比例风格化、空手攻击、独立锤子握持，最后制作2D外观与动作。

目前没有找到并验证可直接复用的高质量单手持锤完整动作；不能把行走或简单手臂动作改名当攻击交付。具体攻击需要继续筛选有明确许可的参考或人工制作，再验证肩胯发力、脚接触、握指与遮挡。主体结构参照、动作数据合法导入、最终美术验收是三个不同结论。
