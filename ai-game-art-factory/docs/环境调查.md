## 已验证的调用方式

从 `ai-game-art-factory` 目录执行：

```sh
python3 scripts/doctor.py --output reports/environment-cloud.json
blender --background --factory-startup --python path/to/script.py -- [script arguments]
godot --headless --version
```

Blender 已实际运行一段读取 `bpy.app.version_string` 与内置 Python 版本的脚本。探针没有创建或保存 `.blend` 文件。

Godot 的版本查询伴随 Fontconfig 不可写缓存警告，Inkscape 查询伴随不可写用户配置目录警告。若后续渲染需要缓存，可将 `XDG_CACHE_HOME`、`XDG_CONFIG_HOME` 指向项目外可写工作目录；不要重设 `HOME`，不要据此关闭 TLS 或其他校验。这里没有把版本查询成功扩大解释为渲染已经成功。

## Windows 本地探查方法

在已经安装 Python 的 Windows 终端进入项目目录：

```powershell
py -3 scripts/doctor.py --output reports/environment-windows.json
```

若 ComfyUI 使用另一个本地端口：

```powershell
py -3 scripts/doctor.py --comfy-url http://127.0.0.1:8189 --output reports/environment-windows.json
```

脚本优先使用 PATH；Windows 再检查少量标准安装目录与 `App Paths` 注册表项。便携版放在任意目录时可能未被发现，可在当前终端将已知工具目录加入 PATH 后重跑。脚本只允许回环 ComfyUI URL，防止把云端 `localhost` 误认为用户 PC，也不会提交 `/prompt` 推理任务。

对于 ComfyUI，请先使用用户现有安装的启动器。标准源码安装常见 `python main.py`，便携版可能有专用 `.bat`，但当前没有验证其实际路径和 Python 环境，因此不提供一个声称已在用户机器跑通的启动命令。

成功访问 `/object_info` 只证明节点接口存在，不证明任何特定 checkpoint、ControlNet 或时序模型可用。之后仍需记录模型文件哈希、许可、节点版本、API 工作流、种子和峰值显存；**未经确认不下载模型**。

## 可替代路径与未决项

- 没有 ComfyUI 时，可先用现有图像生成能力制作待审原画，保存原始结果、提示词与文件哈希；如服务不公开 seed 或模型版本，应记录 `not_exposed`，不能编造可复现性。此路径不能替代 ComfyUI 的时序实验结论。
- 路线 B 的部件变换、握点、遮挡和关节压力测试可以使用经过确认或明确标记待审的 2D 部件，在 CPU 上完成。
- 路线 C 可以先执行 Blender 骨骼/空间约束到 2D 的投影实验；最终部件质量与斜视角变形仍需视觉审查。
- 当前没有接入 Spine 自动化接口，也没有验证其安装或授权。Godot 现有版本是可用的独立实验入口。
- 本次没有新增第三方依赖或下载外部美术。已存在工具的完整发行许可、模型/参考素材的商业使用权和上游维护状态没有逐一在线审查，仍列为引入新资源前的待查项；不会因为工具可以执行就默认所有资源可商用。

已读取实际安装的Python包许可元数据，存于`reports/python-license-inventory.json`：Pillow为MIT-CMU，PyYAML为MIT，NumPy记录了其完整发行许可文本（含捆绑组件说明）。这属于本地许可清单核实，不能代替未来引入模型/节点前的许可与维护状态审查。
