# 现有人形失败审计

结论：当前 B/C 不能继续作为人体动画基线。问题不只是美术细节或部件宽度，而是关节点驱动会使肢段塌缩，原始部件没有按同一个完整人体准确拆分，Blender 结构也不是带层级和蒙皮的人体绑定。应先换成许可明确、来源可追溯的完整素体及其原生骨架/动作，再讨论美术化。

本次只读检查了 `scripts/parts_experiment.py`、`workflows/blender/structure_probe.py`、风格配置、B/C实际导出 JSON，以及现有实际尺寸图、关键帧接触表和结构接触表。没有生成新图、改动图片或更换资产。

## 1. 肢段长度在中间帧严重塌缩

`authored_keys()` 手填肩、肘、腕的像素位置；`interpolate()` 分别对每个关节点做线性插值。它没有通过有固定长度的骨链旋转生成位置，也没有 IK 或关节约束。不同姿态之间的肘腕坐标会相向接近，`along()` 随之把整片手臂纵向压扁。

从 `exports/parts_experiment/{B,C}_hammer_a/animation.json` 的13帧实际关节点计算欧氏长度：

| 路线和肢段 | 最小像素长度 | 最大像素长度 | 最大/最小 |
|---|---:|---:|---:|
| B 右上臂 | 8.846 | 30.232 | 3.418 |
| B 右前臂 | 7.159 | 42.012 | 5.868 |
| B 左前臂 | 18.858 | 32.016 | 1.698 |
| C 右上臂投影 | 17.795 | 30.106 | 1.692 |
| C 右前臂投影 | 3.428 | 27.975 | 8.161 |

B 的右上臂四个关键姿态约为29.73、30.08、27.02、30.23px，但插值帧降到8.85px。这是关键帧接触表很容易漏掉的中间帧故障。仅看4个关键姿态不足以验证13帧结果。

C 的投影长度随视角变化本来就可以变化，不能把所有变化都叫作错误。但当前 C **先取四个3D关键姿态的投影，再在2D平面插值**，没有从原生3D骨架逐帧采样。故无法证明中间帧来自合法人体姿态；不能用真实关键帧的3D骨长恒定替它背书。

两路线右臂“肩→肘”与“肘→腕”的二维叉积在序列中变号。投影姿态跨越视线时也可能变号，所以该指标单独不等于反向折肘；结合这里的极短肢段和无连续关节约束，应当标记人工检查，不应直接放行。

## 2. 当前 Blender Armature 不是已绑定的人体

`armature()` 只为各骨头写入 head/tail；没有设置骨父子层级、连接关系、蒙皮权重或 Armature modifier。`build_body()` 由独立球体、圆柱和方块构成，`animate()` 另外直接移动这些物体。骨架与表面没有通过蒙皮共同变形。

这能做挂点和文件导出的几何测试，但不能验证肘、肩、胯等处的连续人体表面，也不能证明动作能够直接驱动真正的人体模型。不能把“场景里存在 Armature”视为完成角色绑定。

结构中也没有锁骨链、完整多节脊柱、腕掌旋转轴、指骨、踝/足趾链。骨盆、腿和主要躯干保持静止；动作几乎仅改变手臂。对于锤击，重心转移、躯干旋转、肩带运动、膝部缓冲和脚掌支撑尚未建立。

## 3. 部件画片没有共同的人体几何约束

- 图集是另一次 AI 绘制的候选部件，并不是从已经通过审查的完整角色精确拆分。头部自带围巾，躯干又有领口/围巾和肩甲，上臂也含肩甲；重复内容不是单纯改层序即可恢复的解剖连接。
- `along()` 以图片宽度的50%、高度的13%/87%等通用百分比当作关节。它们未必是画中真实肩轴、肘轴、膝轴。自动裁掉透明边界又会改变局部坐标含义。
- 横向宽度与纵向骨长分别缩放，导致护甲、肌肉、手臂的宽长比随动作变化。把宽度39改成40之类的调整无法修复关节轴与原画结构不一致。
- 固定 front_left 头部、手、腿、靴子被放到不同空间姿态中。它们没有相应视角的透视缩短、掌心朝向、腕部旋转、关节补图和局部变形。
- 固定 `body → weapon → front_hand` 层序可以精确重组成自己，却没有表示后掌、握柄、前指的真实包覆。挂点小数误差接近零只说明给定的数学点重合，不说明画出来的手掌握住了柄。

## 4. 现有技术通过遗漏了关键失败

“脚锚不动”来自固定参考坐标；底部 Alpha 不动来自基本不动的腿。它们没有验证脚掌着地、踝关节姿态、身体重心或攻击发力。

“分层重组误差0”验证的是合成可逆性；不能证明人体轮廓、肢体连接和遮挡正确。现有测试应保留为文件/合成检查，但不得再作为人形可用的证据。

风格要求3.5头身、12°俯角和8px边距；现有图像及结构并未完整落实。应先以可靠素体恢复形体，再有明确比例方案地风格化，不能靠逐块压缩身体实现头身比。

## 新基线的最小验收

1. **资源来源**：选择官方或作者公开发布的完整人形素体，保存具体许可、版本、源链接及文件哈希。动作优先使用随该人物原生绑定的动画。公开可浏览不等于允许下载、改作或再分发。
2. **原样导入**：先保留资源原本的身材与骨架，不改成3.5头身，不加盔甲或武器。核实真实 mesh、层级、蒙皮权重、骨名、单位、朝向和 rest pose。没有皮肤权重的线段图不能替代素体。
3. **静态检查**：输出正面、侧面、左右45°的中性姿态，能够连续辨认头颈、胸廓、骨盆、双臂、双腿和完整双手。骨架叠加仅用于核对关节，应同时保留无遮挡的完整表面预览。
4. **原生动作检查**：先播放该素材自带的 walk/idle 等动作，从原生骨骼在每个采样时刻求姿态并渲染蒙皮结果。不要先投影4个姿态再插值坐标。连续播放并检查中间帧，而非只截关键姿态。
5. **技术断言**：检查3D rest bone length与连续帧的骨缩放、蒙皮非空、必需关节和层级、左右映射、完整帧数及曲线采样。检测异常骨缩放、关节角突变、肢体穿插风险和接触漂移；不把所有投影短骨长自动判错。
6. **动作扩展**：基础人形通过后，再找明确许可且有兼容骨架的攻击参考；需要重定向时记录映射、rest pose差异、比例和root motion，先验证空手动作。最后才绑定独立锤子、校准腕掌与手指、验证握持和遮挡。
7. **风格化与2D制作**：人体基线过关后，才设计3.5头身角色的整体比例，再制作/精修2D美术。自然比例素体是解剖和动作参考，不是最终画风，也不能直接替代原画验收。

当前B/C失败文件可保留回归对照，但不建议继续修补为主干。下一份可视交付应是公开可靠素体的原样导入和原生动作证据，而非另一批自动拼接角色。
